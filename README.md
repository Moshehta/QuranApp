# 🕌 منظومة إدارة مقرأة تحفيظ القرآن الكريم

نظام ويب متكامل وسحابي لإدارة مقرأة تحفيظ قرآن كريم (حلقات التحفيظ)، تسجيل وتسميع الجلسات اليومية، ومتابعة الطلاب وأولياء الأمور والمصروفات، مع مشغل كامل للمصحف المسموع.

---

## 🌟 أبرز مميزات النظام

1. **إدارة جلسات التسميع بمرونة تامة:**
   - **اللوح:** حقل نصي حر لتسجيل أكثر من سورة وآية بحرية مع التقدير.
   - **الصحة:** حقل نصي حر للمطلوب للمرة القادمة، مع الربط التلقائي والذكي (نسخ اللوح تلقائياً في حال التقديرات: ضعيف / متوسط / جيد).
   - **الماضي:** تسجيل الماضي المطلوب، مع تكراره تلقائياً إذا كان تقدير المرة السابقة (متوسط / ضعيف) مع إمكانية التعديل.
2. **نظام الأدوار والصلاحيات الدقيق:**
   - **الأدمن (الشيخ المشرف):** إدارة كاملة للطلاب، الجلسات، التقديرات النهائية، والمدفوعات.
   - **طالب محفظ:** طالب متقدم يرى الطلاب ويسمع لهم الماضي فقط (يسجل الأخطاء والتشكيلات وتوقيعه)، مع حظر تلقائي وصارم لتسميع نفسه أو أيٍ من إخوته.
   - **طالب:** يرى ملفه وجلساته وتقييماته فقط.
   - **ولي أمر:** يتابع جلسات أبنائه المرتبطين برقم هاتفه فقط.
3. **🎧 المصحف المسموع (114 سورة):**
   - مشغل صوتي متكامل وسريع بتلاوة فضيلة الشيخ **محمود خليل الحصري**.
   - دعم التكرار للتحفيظ، التحكم في سرعة الصوت (0.75x إلى 1.5x)، شريط التقديم والترجيع، وشريط بحث فوري.
4. **توليد الحسابات التلقائي:**
   - كود الطالب يبدأ من 100 ويزداد تلقائياً.
   - حساب ولي الأمر يتولد تلقائياً من آخر 4 أرقام من رقم هاتفه.
5. **تصميم متجاوب وسريع (Mobile-First):**
   - خط Cairo العربي الواضح.
   - عرض بطاقات حديث يناسب شاشات الهواتف المحمولة.
   - زر تحديث بيانات فوري وسلس (Refresh).

---

## 🛠️ التقنيات المستخدمة

- **الواجهة الأمامية (Frontend):** React.js + Vite + Bootstrap 5 (RTL) + Axios
- **الواجهة الخلفية (Backend):** Node.js + Express.js + JWT Authentication + bcrypt
- **قاعدة البيانات (Database):** Microsoft SQL Server (أو PostgreSQL السحابي عبر Supabase)

---

## 🚀 طريقة التشغيل محلياً

### 1. تشغيل الواجهة الخلفية (Backend)
```bash
cd quran-backend
npm install
# تأكد من إعداد بيانات الاتصال في ملف .env
node server.js
```

### 2. تشغيل الواجهة الأمامية (Frontend)
```bash
cd quran-app
npm install
npm run dev
```

افتح المتصفح على: `http://localhost:5173`
